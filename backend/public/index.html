Academic Certificate Verification

A college project using Solidity, Node.js and PostgreSQL.

Demo mode: certificates, PDFs and their history are temporary. User accounts are saved between runs.

Checking services...

Verify a certificate file

This checks whether your file is exactly the file registered on the blockchain.

The browser calculates SHA-256 locally. Only the hash is sent for this check; the file stays on your computer.

Check academic details

Enter the details from the certificate and compare them with the institution's registered academic record.

This is a separate check of the fields you enter. It does not read a PDF or prove that an uploaded file is genuine. Capitalization and extra spaces are ignored; certificate IDs are case-sensitive.

Find a certificate

Enter the document hash to see its current status, correction links and transaction history.

Issue or correct a certificate

Upload the final PDF and enter the academic details shown on it. Both the file hash and the academic-details hash are registered.

For a correction, use a new ID such as ACV-2026-001-R1 and a new PDF. The old record will show SUPERSEDED. Its history is kept.

Saved certificates

Certificates from this demo session only. Stopping the backend clears them, including their PDF files and history.
